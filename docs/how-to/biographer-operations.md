# Biographer operations

Updated 2026-11-16.

Use `/biographer` for owner project usage, live access and free allowance extensions. Commands require Admin authentication and WebApp OIDC audience `BIOGRAPHER_INTERNAL_AUDIENCE`; allowlist the Admin runtime service account in WebApp. WebApp owns transactional command audit and idempotency. Admin does not read raw recordings or mutate core tables directly.

Configure `biographerBookGeneration`, `biographerAudioBookGeneration` and `biographerPrintOrder` in Services. Do not assume existing short-book prices cover long books. Purchase remains disabled where active pricing is absent.

Phase 1 uses the owner participant only. Phase 2 adds contributor metrics without changing the core command boundary. Migrations are generated by WebApp/SGW and tested on isolated databases; never apply fixtures to the shared development/production database.
