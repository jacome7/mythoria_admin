# Story Whisperer voice support

Open Story Whisperer in Admin and select an interview. The remaining minutes and access state apply to the author across all interviews. The pilot includes 180 minutes per author. Pausing access blocks new admissions and stops active calls at their next lease check. Typing remains available.

Enter a reason to extend time or change access. Admin sends the existing project identifier, acting staff identity and a stable request identifier to the WebApp domain API. WebApp resolves the author and audits each change independently of the lifetime of the interview. Retry an interrupted command with the same request identifier.

The standard wizard sets book prices. Admin staff see operational metadata only. WebApp owns the schema and migration for author allowances.
